# Песни в картинках

Сайт для детей, которые учат песни. Каждая строчка песни — картинка с подписью. Ребёнок собирает куплет из перемешанных картинок (правильные отмечаются зелёной галочкой), а потом поёт по ним куплет или всю песню. Песню можно распечатать на листе А4.

## Что где лежит

```
index.html          главная: сразу открывает первую песню из songs/index.json
song.html           страница песни по ссылке song.html?song=<имя>
pesni.html          список всех песен (ссылка «← Все песни» появляется, когда песен больше одной)
assets/             стили и скрипты сайта
images/             акварельные картинки (svg) и их список images/pictures.json
songs/index.json    список песен; первая в нём открывается на главной
songs/<имя>.json    файл каждой песни
_tools/             ваши инструменты: конструктор и вставка слов (на сайт не попадают)
```

## Кто может менять сайт

Только вы. Посетители сайта могут смотреть, играть и печатать, но ничего не могут изменить: песни и картинки меняются только в вашем репозитории на GitHub, а писать в него можете только вы (пока вы сами не добавите кого-то в **Settings → Collaborators**).

Папка `_tools` на сайт не публикуется: GitHub Pages пропускает папки, имя которых начинается с подчёркивания. Конструктор и скрипт работают только у вас на компьютере.

## Как опубликовать сайт на GitHub

1. Создайте на GitHub новый репозиторий, например `pesni-v-kartinkah`.
2. Загрузите в него всё содержимое этой папки: **Add file → Upload files**, перетащите файлы и папки, нажмите **Commit changes**.
3. Откройте **Settings → Pages**. В разделе **Build and deployment** выберите **Deploy from a branch**, ветку `main` и папку `/ (root)`, нажмите **Save**.
4. Через минуту-две сайт откроется по адресу `https://<ваш-логин>.github.io/pesni-v-kartinkah/`.

Эту ссылку можно отправлять родителям. Ссылка сразу на песню выглядит так:
`https://<ваш-логин>.github.io/pesni-v-kartinkah/song.html?song=ya-risuyu-rodinu`

## Как вписать слова в песню «Я рисую Родину»

В файле `songs/ya-risuyu-rodinu.json` картинки уже расставлены, а поля `"text"` пустые. Слова вписываются одной командой из вашего текстового файла:

1. Положите файл со словами в папку репозитория, например `slova.txt`. Формат как обычно: название, «Слова …», затем «1 куплет», строчки, «2 куплет» и так далее; пустые строки внутри куплета не мешают.
2. В папке репозитория выполните:

```
python _tools/vstavit_slova.py songs/ya-risuyu-rodinu.json slova.txt
```

3. Скрипт впишет строчки по порядку к уже стоящим картинкам и сообщит, сколько вписано. Если число строчек в куплетах не совпадёт, он ничего не изменит и подскажет, где расхождение.
4. Загрузите обновлённый `songs/ya-risuyu-rodinu.json` на GitHub (**Add file → Upload files**, файл заменится). Сам `slova.txt` загружать не нужно.

Можно и вручную: открыть файл на GitHub, нажать на карандаш (**Edit**) и вписать каждую строчку между кавычками: `{"text": "строчка", "pictures": ["drawing"]}`.

Пока слова не вписаны, игра работает: голос и подсказки называют подписи картинок.

## Как добавить новую песню

1. Запустите сайт у себя на компьютере (см. «Проверка на своём компьютере») и откройте конструктор: `http://localhost:8000/_tools/konstruktor.html`.
2. Заполните название, авторов, ссылку на запись и вставьте текст песни.
3. Нажмите **«Разложить по картинкам»**. Картинки подберутся по словам в строчках; любую можно поменять, нажав на неё.
4. Нажмите **«Посмотреть, как получится»**, чтобы проверить игру.
5. Скопируйте **файл песни** и создайте на GitHub файл `songs/<имя>.json` (**Add file → Create new file**), вставьте текст, сохраните.
6. Скопируйте **строчку для списка песен** и добавьте её в `songs/index.json` через запятую. Какая песня стоит в списке первой, та и открывается на главной странице:

```json
[
  {"id": "ya-risuyu-rodinu", "title": "Я рисую Родину", ...},
  {"id": "novaya-pesnya", "title": "Новая песня", "cover": "sun"}
]
```

## Устройство файла песни

```json
{
  "title": "Название песни",
  "credits": "слова …, музыка …",
  "listen": {"label": "Надпись на кнопке", "url": "https://youtu.be/…"},
  "verses": [
    [
      {"text": "строчка", "pictures": ["sun"]},
      {"text": "строчка", "pictures": ["mom", "friends"], "caption": "Мама и друзья"}
    ]
  ]
}
```

- `verses` — куплеты, каждый куплет — список строчек.
- `pictures` — одна или две картинки на строчку.
- `caption` — подпись под картинкой (необязательно; по умолчанию берутся названия картинок).
- `credits` и `listen` можно не писать.

## Картинки

Готовые картинки лежат в `images/`, их названия и подписи — в `images/pictures.json`:

| имя | подпись | имя | подпись |
|---|---|---|---|
| drawing | Рисунок | grove | Роща |
| field | Поле | river | Речка |
| church | Церковь | sun | Солнце |
| cloud | Облака | summer | Лето |
| mom | Мама | brook | Ручеёк |
| friends | Друзья | daisy | Ромашки |
| dawn | Рассвет | path | Тропинка |
| horse | Всадник | rainbow | Радуга |
| me | Я | homeland | Родина |
| star | Звёздочка | | |

**Своя картинка.** Загрузите файл (png, jpg или svg) в папку `images/` и укажите путь прямо в песне: `"pictures": ["images/kot.png"]`. Подпись тогда лучше задать через `caption`.

**Картинка в общий список.** Чтобы конструктор сам подставлял вашу картинку, добавьте её в `images/pictures.json`:

```json
"cat": {"file": "images/kot.png", "label": "Кот", "keywords": ["кот", "кош"], "exact": []}
```

`keywords` — начала слов, по которым конструктор узнаёт строчку («кош» подойдёт к «кошка», «кошку»). `exact` — слова целиком (например, `"я"`).

## Проверка на своём компьютере

Если открыть `index.html` двойным щелчком, браузер не даст сайту прочитать файлы песен. Запустите в этой папке простой сервер и откройте `http://localhost:8000`:

```
python -m http.server 8000
```

## Голос

Сайт читает строчки голосом самого устройства и сам выбирает самый естественный женский русский голос. Выбрать другой голос и скорость можно по ссылке «Голос и печать» внизу страницы песни. На iPhone лучше всего звучит «Milena (улучшенный)», на Windows в браузере Edge — «Svetlana Online (Natural)».

## Статистика (GoatCounter)

1. Зарегистрируйтесь на [goatcounter.com](https://www.goatcounter.com/) и придумайте имя счётчика, например `poem-po-kartinkam`.
2. Откройте файл `assets/stats.js` и впишите это имя в строку:

```js
const GOATCOUNTER_CODE = 'poem-po-kartinkam';
```

3. Отправьте изменения на GitHub (Commit → Push). Через пару минут посещения начнут появляться на `https://<имя>.goatcounter.com`.

Что считается:

| в статистике | что это |
|---|---|
| `/pesnya/<имя>` | открыли песню (главная тоже считается как песня, которая на ней открывается) |
| `/pesni.html` | открыли список песен |
| `sobrali-kuplet-1`, `-2`, `-3` | ребёнок собрал куплет из картинок до конца |
| `speli-kuplet-1` … / `speli-vsyu-pesnyu` | спели по картинкам куплет или всю песню |
| `poslushali-golosom` | нажали «Послушать весь куплет / всю песню» |
| `zapis-hora` | открыли запись хора |
| `pechat` | распечатали песню |

GoatCounter не ставит cookie и не собирает личных данных посетителей.

## Ударения и произношение

Если голос неправильно произносит слово, впишите его в файл `pronounce.json` в корне сайта: слева слово как написано (маленькими буквами), справа — как читать, со знаком ударения сразу после ударной гласной.

```json
{
  "коняшке": "коня́шке"
}
```

Знак ударения можно скопировать из этого файла. На экране слово остаётся без изменений, меняется только то, как его читает голос. Проверить произношение можно на странице песни: «Голос и печать» → «Проверить произношение». Большинство голосов Google и Microsoft знак ударения понимают; если какой-то голос его не слушается, выберите там же другой голос.
